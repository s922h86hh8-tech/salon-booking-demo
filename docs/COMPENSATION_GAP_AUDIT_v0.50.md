### B. 新しく判明した不足事項（優先度と実装方針）

| 優先 | 不足しているもの | 具体的な問題と実装方針 |
|---|---|---|
| P0 | **日付をまたいでも一意の識別子** | 現行デモは予約IDや会計記録番号が日別に再使用される。本番の月次報酬計算で混同しないよう `tenantId, storeId, bookingUUID, serviceUUID, receiptUUID, settlementUUID` を導入。予約の移動は元予約と新予約を関連づける。 |
| P0 | **契約と代金の受け取り方** | 店舗売上→委託報酬なのか、セラピスト売上→場所代／代理受領なのかを先に決める。誰がお客様に役務を販売し、請求書を出し、返金責任を負うかで帳簿が異なる。 |
| P0 | **施術完了の確認** | 「予約を入れた」だけでは委託報酬が発生したと決めない。施術完了・当日取消・無断キャンセル・施術中止・返金・チャージバックを個別のイベントに分ける。 |
| P0 | **契約の版管理と期間** | スタッフごとの％、計算基準、適用開始・終了、誰が承認したか、例外を版として保持。確定した古い月の報酬額を設定変更で書き換えない。新規ルールは過去に遡及させない。 |
| P0 | **報酬計算の定義** | 通常料金、割引後、割引の店舗負担、施術時間、指名料、延長、回数券・ギフト券・商品券、税込／税抜、端数処理、スタッフ2名の分配、キャンセル料、返金・手数料を契約ごとに定義。 |
| P0 | **支払期限・支払状況** | 締め日と支払日は別。契約上の支払期日と実際の振込日、振込証憑、未払残額を分ける。フリーランス法の適用と60日ルールを取引ごとに判断。 |
| P0 | **給与と業務委託の峻別** | 業務委託という名前だけで雇用関係を否定できない。雇用の場合は給与／勤怠／源泉徴収／社会保険など別システムとして管理する前提。 |
| P0 | **真正な本人確認と権限** | 店舗管理者・経理担当・セラピスト本人で閲覧できる金額を分離。給与／報酬／契約変更・支払確定は承認と改ざんされにくい操作履歴を必要とする。 |
| P0 | **本番DBと復旧** | 端末の再読み込みで消えるデモは本番不可。永続保存、トランザクション、同時更新排他、バックアップ・復元、変更前後・日時の証跡が必要。 |
| P1 | **報酬元帳（台帳）** | 1件の施術ID／会計ID／契約版から仮報酬を生成→確認→月締め→確定→支払い→訂正差分。繰り返し同じ会計を取り込んでも二重計上しない。 |
| P1 | **年間資料の所得区分** | 取引日・役務提供日・請求日・確定日・支払日を別列で保存。入金日の年間合計をそのまま「申告上の売上」と断言しない。 |
| P1 | **税・インボイス** | 課税区分、適格請求書発行事業者登録番号、消費税の処理区分、仕入税額控除、経過措置の適用期間を将来検討。源泉徴収や支払調書を業務委託全員に一律適用しない。 |
| P1 | **明細・請求書・出力** | セラピストの月次報酬明細、未払・支払済み、店舗別売上／場所代、年間CSV／印刷用PDF、会計ソフトへ渡すデータを分離。出力は架空デモから試す。 |
| P1 | **スタッフ退職・コース休止** | 退職・料金改定・コース停止でも過去予約や精算記録が消えない。有効開始・終了、非公開・休止を履歴付きで管理。 |
| P1 | **客観的な支払証憑** | 振込完了の確認・振込データの証憑と、アプリで「支払済み」にした操作は別。異議申立て・訂正・再計算の記録を残す。 |
| P2 | **経営分析** | 店舗売上（税区分別）と業務委託報酬・場所代・決済手数料などを分離して、スタッフ別・コース別・予約経路別の収支を集計。実際の利益は他の経費も必要。 |
| P2 | **労務・福利** | スタッフの固定シフト・就業時間だけで業務委託と認定しない。労働者性の相談・判断は別途専門家。業務委託者に給与台帳を当てはめない。 |

### C. 法令で特に注意する点（一次情報で確認）

1. **フリーランス取引条件の明示と支払期限**：公正取引委員会の2026年案内では、対象となる業務委託で報酬額・支払期日等を具体的に明示し、給付受領日から起算して原則60日以内のできる限り短い期間で支払期日を決めることが示されている。「60日以内」とだけ書いても特定の支払期日にはならない。対象の判定は別途必要。\
一次資料：https://www.jftc.go.jp/freelancelaw_2026/
2. **振込手数料の控除**：同案内によると、**2026年1月1日以降に業務委託する対象取引**では、発注時に事前合意があっても振込手数料を報酬から差し引くことは報酬の減額に該当する。自動控除しない設計が必要。2025年以前の例外条件は別途確認する。\
一次資料：https://www.jftc.go.jp/freelancelaw_2026/
3. **労働者性**：厚生労働省は、契約書の名称でなく労働実態から個別判断すると明示。店舗側の就業指示、拘束、代替性などを無視しない。\
一次資料：https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/keiyaku/index02.html
4. **所得税の計算**：国税庁では事業所得の計算を総収入金額−必要経費と説明している。月別報酬の集計だけでは申告書の所得金額を完成できない。\
一次資料：https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1350.htm
5. **帳簿と請求書**：国税庁は青色申告で日々の取引記録と帳簿・証拠書類の保管を説明している。モックのCSVだけでは適法な帳簿保存を保証できない。\
一次資料：https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2070.htm
6. **インボイス仕入税額控除**：国税庁は取引相手・日付・役務・対価の記帳と、原則として関係書類の保存などが必要と説明している。税区分・登録番号の有効期間と書類への紐づけが必要。\
一次資料：https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6497.htm
7. **2026年度税制改正**：国税庁の案内では、適格請求書発行事業者以外からの課税仕入れに関する経過措置は2026年10月から2年間70%、2028年10月から2年間50%、2030年10月から1年間30%へ見直されたとある。実際の適用は課税期間等の条件もあり、単純な固定比率を実装しない。\
一次資料：https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/invoice-review/index.htm
8. **源泉徴収**：国税庁の源泉徴収対象となる報酬・料金は法令で定められた範囲。リラクゼーションを含むすべての業務委託報酬に一律適用したり、自動で支払調書提出が必要と表示しない。\
一次資料：https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2792.htm

### E. 確認すべき業務上の分岐（決め打ちしない）

- お客様の売上の帰属先は、店舗か各セラピストか。
- 報酬対象は施術完了時・会計時・請求時のどれか。指名料やキャンセル料の対象額はどうなるか。
- 割引は店舗負担かセラピスト負担か。
- 歩合は割引前か後か、税抜か税込か、端数の処理は各施術か月合計か。
- 支払締め日・具体的な支払日・支払方法は何か。
- セラピストは適格請求書発行事業者か、必要な発行書類はどれか。
- 本人が売上・経費を把握しているか、本人売上の代理受領があるか。

**これらを決める前に、本番の報酬を自動確定することはしない。**
